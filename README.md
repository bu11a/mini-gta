# Нулевая полоса

Аркадная игра-погоня от полиции (HTML, CSS, JavaScript) с сервером на Node.js. Можно играть гостем или завести аккаунт: тогда прогресс хранится на сервере и попадает в таблицу рекордов.

## Запуск

Нужен Node.js 18 или новее. Внешних пакетов нет, `npm install` не требуется.

```bash
cd nulevaya-polosa
npm start          # или: node server.js
```

Откройте http://localhost:3000 в браузере.

Настройки задаются переменными окружения:

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Адрес, на котором слушать |
| `DATA_DIR` | `./data` | Папка с базой `db.json` |
| `COOKIE_SECURE` | выкл. | `1` — ставить cookie с флагом `Secure` (включайте, когда сайт работает по HTTPS) |
| `TRUST_PROXY` | выкл. | `1` — брать IP клиента из `X-Forwarded-For` (если сервер стоит за nginx и т. п.) |

Пример для продакшена за nginx с HTTPS:

```bash
PORT=8080 COOKIE_SECURE=1 TRUST_PROXY=1 DATA_DIR=/var/lib/nulevaya-polosa node server.js
```

## Режимы игры

- **Гость.** Прогресс (деньги, улучшения, пройденные миссии, рекорд) хранится в `localStorage` этого браузера. Сервер не нужен: `public/index.html` можно открыть и как обычный файл, тогда работает только гостевой режим.
- **Никнейм.** Его видят другие игроки в таблице рекордов. Указывается при регистрации или при входе гостем; сменить можно в любой момент ссылкой «сменить ник» вверху меню. 2–24 символа: буквы любого языка, цифры, пробелы, `_ . -`. Ники уникальны без учёта регистра. Логин для входа — отдельный и другим игрокам не показывается.
- **Аккаунт.** Регистрация по логину, паролю и никнейму. Прогресс сохраняется на сервере автоматически, примерно через секунду после каждого изменения, и загружается при входе с любого устройства. При регистрации можно перенести прогресс гостя.
- При первом заходе показывается окно: войти, создать аккаунт или играть гостем. Позже это можно сделать кнопками вверху меню.

## Структура

```
server.js          сервер: API и раздача файлов из public/
package.json
public/
  index.html       разметка: меню, HUD, окно входа
  style.css        стили
  account.js       гостевой режим, вход, регистрация, синхронизация, рекорды
  game.js          сама игра (город, физика, полиция, миссии, гараж)
  favicon.svg
data/db.json       создаётся автоматически: пользователи, сессии, прогресс
```

## API

Все ответы в JSON. Сессия хранится в cookie `sid` (HttpOnly, SameSite=Strict).

| Метод и адрес | Тело | Ответ |
| --- | --- | --- |
| `POST /api/register` | `{username, password, nickname, progress?}` | `201 {user, progress}` и cookie |
| `POST /api/login` | `{username, password}` | `200 {user, progress}` и cookie |
| `POST /api/logout` | — | `200 {ok}` |
| `GET /api/me` | — | `200 {user, progress}` или `401` |
| `PUT /api/progress` | `{progress}` | `200 {progress}` |
| `PUT /api/profile` | `{nickname}` | `200 {user}` или `409`, если ник занят |
| `GET /api/leaderboard` | — | `200 {top: [{nickname, best}]}`, топ-20 |
| `GET /api/health` | — | `200 {ok: true}` |

`user` — `{username, nickname, created}`. Аккаунтам из старой версии без ника при запуске сервера ник проставляется автоматически, равным логину.

Формат прогресса: `{money, up: {engine, armor, nitro, tires}, done: {prologue: true, …}, best}`.

## Безопасность

- Пароли хешируются через scrypt с солью. Сами пароли нигде не сохраняются.
- Токен сессии случайный (32 байта). В базе лежит только его SHA-256, срок жизни 30 дней.
- Вход и регистрация: не больше 10 попыток за 10 минут с одного IP.
- Тело запроса ограничено 16 КБ, принимается только JSON. Прогресс проверяется и обрезается до допустимых значений.
- Заголовки безопасности: CSP, `nosniff`, запрет встраивания во фреймы. Статика защищена от выхода за пределы `public/`.

Ограничение: игра считается в браузере, поэтому сервер доверяет присланному прогрессу. Он лишь проверяет типы и диапазоны, и рекорд не может уменьшиться. Опытный игрок может подделать деньги или рекорд через консоль браузера. Для честной таблицы рекордов нужна серверная проверка результатов. Это отдельная большая задача.

## Хранилище

База — один JSON-файл, запись атомарная (через временный файл). Этого хватит для сотен и тысяч игроков на одном сервере. Для резервной копии достаточно копировать `data/db.json`. Если игроков станет много или понадобится несколько серверов, хранилище стоит перенести в SQLite или PostgreSQL: вся работа с данными собрана в начале `server.js`.

## Управление

W/↑ — газ, S/↓ — тормоз, A D/← → — руль, Пробел — дрифт, Shift — нитро, Q/E/R — глушилка, ЭМИ, масло, P/Esc — пауза, M — звук. На телефоне появляются экранные кнопки.
